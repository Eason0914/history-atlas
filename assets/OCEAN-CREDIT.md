# Decorative ocean photograph

`ocean-surface.jpg` is a photograph by **Adrian Pelletier**, published on Pixnio and identified by the source as **CC0 / public domain**.

- Source page: https://pixnio.com/media/dark-dark-blue-liquid-shadow-surface
- Downloaded display image: https://pixnio.com/free-images/2019/08/30/2019-08-30-10-01-45-1200x800.jpg
- License: https://creativecommons.org/publicdomain/zero/1.0/

The file is stored locally so the site works offline. Its display is refracted and tinted by the Liquid Glass renderer. This is decorative ocean texture, not geographic ocean imagery, bathymetry, or a historical source. It is separate from the classroom images counted in the slide library.

The optical design was informed by the reference supplied by the user: https://github.com/lucasromerodb/liquid-glass-effect-macos . The atlas uses an original WebGL renderer and its own SVG fallback and button decoration code; no third-party application code is bundled.
